<h1 align="center">XUtil</h1>
<p align="center">A Minecraft Fabric utility mod for quality of life.</p>
<p align="center">Current version: 1.2.0</p>
</p>

## Usage

### Building
- Clone this repository
- Run `./gradlew build`

### Installation
- Install Fabric for Minecraft 26.2
- Drop the jar from `build/libs/` into your `mods` folder
- Press `DEL` in-game to open the ClickGUI

## Contributions
- Follow the code style already used in the project
- IDE or system files belong in the `.gitignore`, not in pull requests
- Prefer readability over cleverness
